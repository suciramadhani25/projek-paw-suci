# Task Manager Mahasiswa

Aplikasi web sederhana untuk membantu mahasiswa mengelola tugas kuliah.

## Fitur
- Menambahkan tugas
- Mengedit tugas
- Menghapus tugas
- Mengubah status tugas
- Menyimpan data menggunakan Local Storage

## Teknologi
- HTML
- CSS
- TypeScript
- Vite
- npm
- Git dan GitHub

## Cara Menjalankan
1. Install dependency dengan npm install.
2. Jalankan aplikasi dengan npm run dev.
3. Buka alamat localhost yang muncul di terminal.
