Tentang Dokumentasi

Halaman ini berisi penjelasan mengenai teknologi dan konsep yang digunakan dalam pengembangan aplikasi Task Manager Mahasiswa. Teknologi tersebut membantu proses pengelolaan kode, pengembangan, pengujian, dan pembuatan aplikasi web.

1. Git

Git adalah sistem version control yang digunakan untuk mencatat perubahan kode program. Dengan Git, pengembang dapat melihat riwayat perubahan, membuat branch, melakukan merge, dan kembali ke versi sebelumnya jika diperlukan.

2. npm

npm (Node Package Manager) adalah alat untuk mengelola package atau library JavaScript. npm digunakan untuk memasang dependency dan menjalankan perintah pengembangan seperti npm install, npm run dev, dan npm run build.

3. TypeScript

TypeScript adalah bahasa pemrograman yang dikembangkan dari JavaScript dengan dukungan tipe data. TypeScript membantu pengembang menemukan kesalahan tipe data lebih awal dan membuat kode lebih terstruktur.

4. Vite

Vite adalah build tool yang membantu proses pengembangan aplikasi web. Vite menyediakan development server untuk menjalankan aplikasi secara lokal serta proses build untuk menghasilkan file siap produksi.

5. Environment Variable

Environment variable adalah variabel konfigurasi yang nilainya dapat disesuaikan berdasarkan lingkungan aplikasi. Dalam project Vite, variabel yang dapat diakses dari kode frontend menggunakan awalan VITE_. File .env digunakan untuk menyimpan konfigurasi lokal, sedangkan .env.example menjadi contoh variabel yang dibutuhkan.

6. Compiler

Compiler adalah program yang menerjemahkan kode sumber menjadi bentuk lain yang dapat diproses atau dijalankan. Pada project ini, TypeScript menggunakan compiler untuk memeriksa tipe data dan menghasilkan JavaScript.

7. Transpiler

Transpiler adalah alat yang mengubah kode dari satu bahasa atau versi bahasa pemrograman ke bentuk lain yang setara. Contohnya, TypeScript ditranspilasi menjadi JavaScript agar dapat dijalankan oleh browser.

8. Bundler

Bundler adalah alat yang menggabungkan berbagai file dan module aplikasi menjadi kumpulan file yang siap digunakan. Dalam proses build, Vite menggunakan Rollup untuk melakukan bundling pada aplikasi produksi.

9. Dependencies

Dependencies adalah package yang dibutuhkan aplikasi agar dapat berjalan. Package tersebut tercatat dalam bagian dependencies pada file package.json dan dipasang menggunakan npm.

10. DevDependencies

DevDependencies adalah package yang digunakan untuk membantu proses pengembangan, seperti TypeScript dan Vite. Package ini tercatat pada bagian devDependencies di package.json.

11. Semantic Versioning (Semver)

Semantic Versioning adalah aturan penomoran versi package dengan format MAJOR.MINOR.PATCH. MAJOR menunjukkan perubahan besar yang tidak kompatibel, MINOR menunjukkan penambahan fitur yang tetap kompatibel, sedangkan PATCH menunjukkan perbaikan bug. Contohnya adalah versi 1.2.3.
